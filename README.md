# zepto-data-ai-platform
This repository contains my AI/ML Capstone Project.

The project consists of three major modules:

## 1. Data Pipeline

Web scraping, data cleaning, currency conversion, SQLite database management, SQL analysis, and Pandas validation.

## 2. Analytics Pipeline

Exploratory Data Analysis (EDA), machine learning classification, model evaluation, imbalance handling, hyperparameter tuning, regression analysis, and model pipeline deployment.

## 3. GenAI Support Assistant

A Retrieval-Augmented Generation (RAG) based customer support assistant using embeddings, ChromaDB, LangGraph, FastAPI, and Docker.
